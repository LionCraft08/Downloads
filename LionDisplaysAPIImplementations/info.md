# What is that?
Here you can download an Implementation for the LionDisplays API for the platforms Paper, Fabric (Server), Velocity and Folia.
<br>This allows plugins and mods to use the features provided by the LionDisplays Mod.
# Do I need this?
If you don't know, probably not. If a Plugin or Mod requires this Implementation on your server, you will probably find the required version in the plugin/mod's description.
